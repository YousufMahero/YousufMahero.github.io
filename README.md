# 122 DHY Genel KURA MUNHAL COCUK SAĞLIĞI VE HASTALIKLARI KADROSÜ 👩‍⚕️

This repository provides an interactive map of all open **“Çocuk Sağlığı ve Hastalıkları”** positions (122 DHY Genel Kura) across Turkey.

## Files

- **`map.html`**  
  - Displays an OpenStreetMap-based map with markers for each city.  
  - Clicking a marker shows the number of openings and a table of the corresponding institutions.

## Usage

1. Clone or download this repository.  
2. Open **`map.html`** in any modern browser (no server required).  
3. Click on city markers to view details.

## Technologies

- **Leaflet.js** for map rendering  
- **OpenStreetMap** tile layer  
- Plain **HTML**, **CSS**, and **JavaScript**
